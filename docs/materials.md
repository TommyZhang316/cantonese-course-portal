# 教材匯入與發布規則

`scripts/prepare-materials.py` 只讀取 Portal 上一層的 `課程成果` 和 `_work/lesson_01.json` 至 `lesson_08.json`。它建立匯入清單與私有檔案副本，不修改原教材，不連接任何外部服務，不上傳檔案。

## 執行

使用含 `pypdf` 的 Python：

```powershell
python scripts/prepare-materials.py
python scripts/prepare-materials.py --verify-only
```

在本機亦可使用 Codex 提供的 Python 執行環境。毋須 Microsoft Office 或 LibreOffice。清單在 `private-materials/manifest.json`，核對報告在 `private-materials/preparation-report.json`。這整個資料夾已列入 `.gitignore`，不可移入 `public/`、`src/`、`dist/`、GitHub Pages 或任何公開儲存庫。腳本會先檢查忽略規則才開始。

## 不向學生發布的資料

`never` 表示無論日期都不向學生提供。以下是起始安全設定，管理員仍可按實際教學需要修改；資料名稱不會自動決定權限。

| 材料 | 起始設定的理由 |
| --- | --- |
| 原教師 PPTX | 備忘稿內含授課提示及練習解答。學生只使用清理後的副本。 |
| 教師用書 PDF、DOCX | 含所有課堂練習、遊戲及活動的答案。 |
| 教師與助教使用指南 PDF、DOCX | 含答案位置、分發頁碼與期末運作細節，供授課團隊使用。 |
| 全套互動角色卡 PDF、DOCX | 資訊差活動要求每人只看自己的角色，整套提前下載會破壞活動。教師按需要分發單張。 |
| 全課離線遊戲 HTML 與 CSV 題庫 | 含後續所有課次的問題及答案，作教師投影工具。 |
| 遊戲使用說明 | 配套教師投影與操作流程，與全課遊戲一起管理。 |
| 正式期末筆試學生卷 PDF、DOCX | 雖稱「學生卷」，仍是正式試卷，預設由教師在考場發放。 |
| 期末答案與命題藍圖 PDF、DOCX | 包含正式評核答案及配分，僅供評核人員。 |
| 原始大綱封存 DOCX | 保留給課務核對，學生以現行修訂大綱為準，避免兩版安排混淆。 |
| 教學參考研究 Markdown | 教師備課比較與來源研究，非學生學習材料。 |

整套 ZIP、舊材料入口 HTML、一般文件清單與封存核對記錄不匯入。舊入口內有直接教師檔案連結，不能作為公開網站入口。工作資料夾 `_work` 除八堂的課程日期、標題及學習目標外不匯入。使用者提供的第三方整本教材 PDF 及原教材錄音不包含在此匯入範圍。

## 學生 PPTX 的處理與檢查

腳本以 OOXML 封裝層級製作副本，移除全部備忘稿頁與備忘稿母片、批註與批註作者、相關關係、相關內容型別及自訂 XML。原文件屬性與縮圖也移除，只重建含「學生版」檔名的最小標題屬性。

它逐一檢查壓縮包完整性、XML 可解析性、每個內部關係目標、每個 `r:id` 和內容型別引用，確認沒有懸空引用。八份學生版的每一張可見投影片 XML 與原教師版逐位元組相同，版式及課堂題目保持一致。教師專用解答備忘稿不會進入學生檔。

目前八份原簡報均沒有隱藏投影片、嵌入附件、巨集或外部連結。如果將來原檔出現這些內容，腳本會停止，要求先作人工內容審核，不會悄悄將可能藏有私密資料的簡報設為學生可用。移除備忘稿不能判斷可見畫面是否含機密；新增或修改投影片的教師仍須核對可見內容適合學生。

## 匯入介面與可重複執行

Manifest 格式：

```json
{
  "schema_version": 1,
  "lessons": [],
  "resources": []
}
```

`lessons` 包含 `id,title,summary,starts_at,duration_minutes,sort_order`。每堂 120 分鐘。

每個 `resources` 項目包含資料庫欄位 `id,title,description,lesson_id,category,student_policy,release_at,mime_type,file_size,file_name,storage_path`，加上本機匯入用的 `local_path,sha256`。`local_path` 相對於 `private-materials`，後兩欄不得傳入資料庫。

資源 UUID 由穩定教材鍵產生；檔案版本 UUID 由資源 UUID 與檔案 SHA-256 產生。同一份內容重跑有相同資源 ID 及檔案路徑。內容變更時保持資源 ID，產生新的不可變檔案路徑。中文下載檔名保存在 `file_name`，儲存路徑採 `resources/<資源 UUID>/<版本 UUID>/material.<副檔名>`。

初次匯入由受信任的操作端把檔案上傳至私有 `course-materials` bucket，檢查大小與雜湊，再新增資料列。正式使用後，重新執行本腳本只會重建本機預設清單；匯入端應保留後臺已修改的權限、發布時間與課表，不應直接用初始清單覆蓋管理員決定。舊檔副本保留在私有暫存目錄，腳本不執行刪除。

已下載到個人裝置的副本無法藉由更改 Portal 權限收回。權限變更會限制後續線上存取。清單與報告不含管理員電郵或任何服務金鑰，初始管理員由獨立受信任流程建立。
