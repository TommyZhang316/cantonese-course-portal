# 公益粵語課堂入口使用指南

網站：[公益粵語課堂](https://tommyzhang316.github.io/cantonese-course-portal/)

用手機或電腦瀏覽器開啟即可，不需要 ChatGPT 或 GitHub 帳戶。老師、學生和管理員都從同一網址登入，每人使用自己的課程帳戶。

本指南介紹「管理員建立學生帳戶」新版流程。2026年9月6日更新時，原有網站已發布，首位管理員已啟用；新版部署及正式環境驗收仍待完成，進度見[部署說明](DEPLOY.md)。

## 學生第一次使用

1. 向課程管理員領取帳戶名稱及初始密碼，無須自行申請或提供電郵。
2. 帳戶名稱是中文姓名的普通話全拼音大寫，不加空格。例如「陳小明」為 `CHENXIAOMING`，「呂美玲」為 `LVMEILING`；ü 寫成 V。重名時可能附有02、03，請以管理員派發的名稱為準。
3. 在「帳戶名稱或電郵」填帳戶名稱。初始密碼與帳戶名稱完全相同，請按派發資料輸入大寫字母。
4. 首次登入會顯示「先設定你的專用密碼」。設定至少12個字元、與帳戶名稱不同的新密碼，並再輸入一次確認。
5. 按「儲存密碼並進入課堂」。之後使用這個新密碼登入，原來的初始密碼不再適用。

學生帳戶建立後即啟用，完成首次改密碼便可閱讀已發布材料，毋須再等候批核。名字較短的同學也可使用管理員提供的初始密碼；12字元要求適用於自行設定的新密碼。

## 忘記密碼或需要帳戶

- 使用拼音帳戶的學生：請聯絡管理員重設初始密碼，重新登入後再設定專用密碼。
- 使用電郵登入的教職員：可按「忘記密碼？」收取電郵重設連結；未收到時請聯絡專案負責人核對寄信服務。
- 尚未有帳戶：向課程管理員領取。入口沒有自行申請帳戶的功能。
- 共用電腦用完後，按右上角「登出帳戶」。

## 學生找材料

登入後在「課程總覽」選擇某一課，或打開「全部材料」搜尋名稱並篩選類型。課程指南等共用文件放在「共用資料」。按材料的下載按鈕取得檔案。

每課學生筆記與學生演示文檔預設在上課前7天、香港時間上午9時開放。例如9月18日上課，對應材料於9月11日上午9時開放。實際以管理員設定為準；時間到了會自動開放，管理員不需要保持網站開着。

尚未發布的附件不會出現在學生材料清單。教師答案、評分準則、教師原版演示文檔等設定為僅教職員，學生不會取得。若顯示「材料尚未開放」，可以先查看「共用資料」。

建議課前先看筆記中的本課目標、粵拼和例句；課後重讀對話並開口練習。手機閱讀可選PDF，需要自行做註解時可下載Word。

## 老師備課

已有電郵帳戶的老師沿用電郵及原有密碼。新增教職員帳戶請由管理員或專案負責人安排。

已啟用的老師可立即下載全部未封存材料，無須等待學生發布時間。先閱讀教師指南，再按課次配合筆記、原版演示文檔、活動及評核材料備課。

教師原版PPT保留授課備忘稿；學生版PPT已移除教師備忘稿。需要向同學派發時，請選學生版材料。老師角色不能修改發布時間或帳戶權限，需要調整時請管理員處理。

## 管理員建立及派發帳戶

登入後按「管理後臺 → 帳戶與權限」。

1. 在「批量建立學生帳戶」每行貼一位中文姓名，或匯入CSV，每批最多50位。
2. 按「產生帳戶預覽」。系統支援繁體及簡體姓名；姓名中的多音字仍需逐一核對，帳戶名稱可直接修改。
3. 同批重名會加02、03；已存在的帳戶會顯示略過，不會改密碼或權限。確認每一行對應正確同學。
4. 按「建立 N 個學生帳戶」。有項目未完成時，修改或重試未完成項目即可，已建立的帳戶不會再建立或重設。
5. 按「下載本批 N 個帳戶（CSV）」。表內只有本批確認建立成功的姓名、帳戶名稱、初始密碼及入口網址。
6. 按同學逐一派發其帳戶資料。網站只下載帳戶表到管理員電腦，不會自動寄信；離開頁面前請保存本批結果。

詳細CSV格式、重設方法及權限管理見[ADMIN.md](ADMIN.md)。

## 管理員安排課程

| 工作 | 頁面與步驟 |
| --- | --- |
| 調整老師或管理員權限 | 「帳戶與權限」→搜尋姓名／帳戶名稱／電郵→「管理權限」→「核對變更」→「確認更新」。 |
| 暫停帳戶 | 同一頁把狀態改為「已停用」。至少保留一位已啟用管理員。 |
| 新增教材 | 「材料與發布」→「新增材料」→選檔案、名稱、課次、類型及學生發布方式→「儲存材料」。 |
| 調整公開時間 | 編輯材料，選「按設定時間發布」，填香港日期及時間；可按「設為上課前一周上午9時」。 |
| 保留教師專用 | 在「向學生發布」選「永不向學生發布・僅教職員」。 |
| 暫時收起材料 | 按「封存」。需要時把清單改為「已封存」，再按「恢復」。 |
| 替換檔案 | 編輯現有材料，在「替換檔案」選新檔案後儲存；沒有選新檔案就保留原檔。 |
| 改上課日期 | 「課次與日期」→編輯課次→儲存；再核對相關材料發布時間。 |
| 查閱變更 | 「操作記錄」查看材料、日期與帳戶的最近修改。 |

改上課日期不會自動覆寫已設定的材料公開時間。兩名管理員同時修改同一項資料時，較後的儲存會提示版本衝突；請記下修改內容後重新讀取核對。

## 分享與常見情況

- 對外分享上方網站網址即可。私人附件需登入並具有權限，轉發下載地址不會替收件人取得權限。
- 已下載的檔案無法由網站遠端收回，因此仍應分清教師版和學生版。
- 「舊有待處理」是以前留下的帳戶狀態。管理員可核對後處理；新批量建立的學生帳戶不用這個流程。
- 可在右上角切換淺色／深色模式。鍵盤使用者可按Tab移動，Enter啟動按鈕，Esc關閉可取消的對話框。
