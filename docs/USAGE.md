# 公益粵語課堂入口使用指南

網站：<https://tommyzhang316.github.io/cantonese-course-portal/>

用手機或電腦瀏覽器開啟即可，不需要 ChatGPT 或 GitHub 帳戶。每人使用自己的課程帳戶；老師、學生和管理員都從同一網址登入。

## 第一次使用

1. 按「申請帳戶」，填姓名、常用電郵及至少12字元的密碼。
2. 到電郵信箱按驗證連結；未收到時檢查垃圾郵件。若仍沒有，聯絡課程管理員，避免連續重複申請。
3. 驗證後登入。新帳戶顯示等待批准，管理員核對報名資料並啟用後才能取用材料。
4. 老師也先申請帳戶，再由管理員設定為「老師」及「已啟用」。申請表不提供自行選擇角色。

忘記密碼時，在登入頁按「忘記密碼？」並依電郵連結重設。共用電腦用完後，按右上角「登出帳戶」。

## 學生找材料

登入後在「課程總覽」選擇某一課，或打開「全部材料」搜尋名稱並篩選類型。課程指南等共用文件放在「共用資料」。按材料的下載按鈕取得檔案。

每課學生筆記與學生演示文檔預設在上課前7天、香港時間上午9時開放。例如9月18日上課，對應材料於9月11日上午9時開放。實際以管理員設定為準；時間到了會自動開放，管理員不需要保持網站開着。

尚未發布的附件不會出現在學生材料清單。教師答案、評分準則、教師原版演示文檔等設定為僅教職員，學生不會取得。若顯示「材料尚未開放」，可以先查看「共用資料」。

建議課前先看筆記中的本課目標、粵拼和例句；課後重讀對話並開口練習。手機閱讀可選PDF，需要自行做註解時可下載Word。

## 老師備課

已啟用的老師可立即下載全部未封存材料，無須等待學生發布時間。先閱讀教師指南，再按課次配合筆記、原版演示文檔、活動及評核材料備課。

教師原版PPT保留授課備忘稿；學生版PPT已移除教師備忘稿。請從學生版材料下載後分享給同學。老師角色沒有修改發布時間或批准帳戶的權限，需要調整時請管理員處理。

## 管理員安排課程

登入後按「管理後臺」。

| 工作 | 頁面與步驟 |
| --- | --- |
| 批准學生或老師 | 「帳戶與權限」→搜尋姓名／電郵→設定角色及「已啟用」→「核對變更」→「確認更新」。 |
| 暫停帳戶 | 同一頁把狀態改為「已停用」。至少保留一位已啟用管理員。 |
| 新增教材 | 「材料與發布」→「新增材料」→選檔案、名稱、課次、類型及學生發布方式→「儲存材料」。 |
| 調整公開時間 | 編輯材料，選「按設定時間發布」，填香港日期及時間；可按「設為上課前一周上午9時」。 |
| 保留教師專用 | 在「向學生發布」選「永不向學生發布・僅教職員」。 |
| 暫時收起材料 | 按「封存」。需要時把清單改為「已封存」，再按「恢復」。 |
| 替換檔案 | 編輯現有材料，在「替換檔案」選新檔案後儲存；沒有選新檔案就保留原檔。 |
| 改上課日期 | 「課次與日期」→編輯課次→儲存；再到「材料與發布」核對相關發布時間。 |
| 查閱變更 | 「操作記錄」查看材料、日期與帳戶的最近修改。 |

改上課日期不會自動覆寫已設定的材料公開時間。兩名管理員同時修改同一項資料時，較後的儲存會提示版本衝突；請記下修改內容後重新讀取核對。

詳細後臺說明見[ADMIN.md](ADMIN.md)。

## 分享與常見情況

- 對外分享上方網站網址即可。私人附件需登入並具有權限，直接轉發下載地址不會替收件人取得權限。
- 已下載的檔案無法由網站遠端收回，因此仍應分清教師版和學生版。
- 已獲批准但仍在等待頁時，按「重新檢查狀態」；頁面也會每分鐘自動更新。
- 忘記密碼信或驗證信一直沒有收到，請管理員檢查寄信服務設定、收件地址及服務額度。
- 可在右上角切換淺色／深色模式。鍵盤使用者可按Tab移動，Enter啟動按鈕，Esc關閉可取消的對話框。
