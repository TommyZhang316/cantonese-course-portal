# 課程入口設計紀錄

模式：保留識別，擴展成課程服務。原頁為本機檔案索引，無已公開網址、搜尋排名或登入表單，沒有需要遷移的SEO路由。

原有色彩：底色 #f9f7f0，深綠文字與按鈕 #193e45，連結 #176456。保留深綠識別，以清楚的繁體中文、粵拼及課次組織為核心。原有課程名稱、八課主題及素材保持。

原索引提供八課表格、教師材料折疊區和直接本機下載。這些只適合教師私下使用，不能把整個索引或原檔公開上傳。新網站的帳戶、存取與定時發布由後端執行。

Design read：給老師、助教及零基礎學生的課程服務網站，清楚、平易，保留深綠識別。DESIGN_VARIANCE=3，MOTION_INTENSITY=2，VISUAL_DENSITY=5。

design-taste-frontend用於入口、登入及學習頁的字體、節奏、圖片和手機體驗。管理後臺是該skill明示不涵蓋的密集產品介面，採用官方Fluent UI React Components及其無障礙表單／對話框，整站只用這一套元件基礎。圖示使用Phosphor。動效僅用於焦點、互動回饋，尊重減少動態設定。

淺色及深色模式採語義色彩變數，同頁不混用不同主題。中文系統字體堆疊為微軟正黑體、PingFang TC、Noto Sans TC及sans-serif；不向外部字體CDN送請求。

主要流程：登入／申請帳戶；課程列表；按課查看已授權資源；教師全部材料；管理員材料發布、課程日期、帳戶權限及操作記錄。空白、等待批准、停用、錯誤、載入狀態均需完整設計。

無障礙：鍵盤完整操作、跳至內容、表單標籤、可讀焦點、足夠對比、時間明示香港時區、手機單欄、錯誤訊息與操作結果即時宣告。會員資料不寫入公開預覽內容。預覽帳戶和資料僅存在明確的本機demo模式，不部署為真實認證。
