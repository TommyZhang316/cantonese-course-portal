# 課程後臺使用

本指南適用於「管理員建立學生帳戶」新版。2026年9月6日更新時，首位管理員已啟用，新版正式環境驗收仍在進行；發布狀態見[DEPLOY.md](DEPLOY.md)。

## 批量建立學生帳戶

登入後打開「管理後臺 → 帳戶與權限」。在「批量建立學生帳戶」貼上名單，每行一位，例如：

```text
陳小明
呂美玲
單宇
```

每批最多50位，超過時請分批處理。也可按「匯入 CSV」，使用Excel的「CSV UTF-8」格式；欄位包括「姓名」及選填的「帳戶名稱」：

```csv
姓名,帳戶名稱
陳小明,
呂美玲,
單宇,SHANYU
```

帳戶名稱留空時自動產生。也支援直接貼上試算表欄位；「中文姓名」、`name`、`username` 等標題亦可辨認。檔案只需提供姓名和選填帳戶名稱，毋須學生電郵。

按「產生帳戶預覽」後，逐一核對：

- 姓名轉為普通話全拼音大寫，不加空格，ü寫成V。繁體及簡體都可辨認。
- 系統會優先辨認姓氏讀音，例如「單宇」為`SHANYU`、「區志強」為`OUZHIQIANG`；多音字可能因人而異，可直接修改預覽中的帳戶名稱。
- 同一批出現相同拼音時，後面的帳戶會加02、03；每一行都保留，不會把同名同學合併。
- 系統已有的帳戶會略過，保留原來的密碼及權限。若是另一位同名同學，請核對身份後在預覽中改用獨立名稱。
- 手動填寫的帳戶名稱不會被默默改成其他名稱；重複或格式錯誤會提示修改。可使用2–60個大寫英文字母或數字，以字母開頭。

確認後按「建立 N 個學生帳戶」。新帳戶是已啟用學生，初始密碼與帳戶名稱相同。學生首次登入必須改成至少6個字元、與帳戶名稱不同的新密碼，之後才可取用材料。

帳戶名稱建立後固定，請在建立前確認拼音。若建立後才發現錯誤，可停用錯誤帳戶，再以正確名稱建立新帳戶。

## 建立結果及派發

完成後按「下載本批 N 個帳戶（CSV）」。表內只包含這次確認建立成功的四項資料：中文姓名、帳戶名稱、初始密碼、入口網址。CSV使用UTF-8並附BOM，方便Excel顯示中文。

有部分項目失敗時，畫面保留每一行結果。按「重試 N 個未完成帳戶」只會再處理未完成項目；已存在帳戶會略過，不會改成密碼重設。若網絡中斷而無法確認結果，先重新整理帳戶清單，再處理未完成項目。未確認成功的項目不會寫入本批派發表。

若重試後又建立了帳戶，請下載更新後的CSV，再按「開始新一批」。結果只保留在目前頁面，離開或重新載入後便會清除。管理員下載後逐一把對應資料交給同學；網站不會自動寄送、群發或把整份名單交給學生。

## 重設學生初始密碼

1. 在「帳戶與權限」搜尋姓名或帳戶名稱。
2. 按該學生的「重設初始密碼」，核對姓名及帳戶名稱。
3. 按「確認重設初始密碼」。初始密碼會重新變成帳戶名稱，原有密碼失效。
4. 把資料交給該同學；下次登入仍須先設定自己的新密碼。

這個按鈕只適用於後臺建立的拼音學生帳戶，不會重設老師、管理員或既有電郵帳戶。重設失敗時依畫面提示重新整理及稍後重試；帳戶會保持需要更改密碼的狀態。

## 帳戶權限及教職員

搜尋姓名、帳戶名稱或電郵，按「管理權限」調整角色及狀態。權限修改會先顯示核對畫面，保存後記錄操作。至少保留一位已啟用管理員。

已有電郵帳戶的教職員沿用原有登入方式。新增電郵教職員帳戶由專案負責人在受信任的Auth後臺安排建立及驗證，再由管理員在入口設定角色及啟用。也可先建立拼音帳戶並設定老師或管理員角色；當事人首次登入仍須更改初始密碼，完成後才可使用該角色的材料及功能。尚未完成首次改密碼的管理員，不會計入系統必須保留的有效管理員人數。

「舊有待處理」保留以前未完成啟用的帳戶。管理員可核對後處理，這不是新生入門步驟。停用帳戶後，新教材請求會失去存取權；已下載到電腦的文件不能遠端收回。

電郵登入帳戶仍支援忘記密碼郵件。正式SMTP尚待專案負責人核對及完成收信測試；學生帳戶建立、派發及初始密碼重設均不需要寄信服務。

## 材料與發布

每項文件分開管理，可用課次、檔案狀態及文字搜尋篩選。新增材料先選檔案、課次和分類，再設定學生發布方式：

- **僅教職員**：學生永遠無法取得，除非管理員改成其他發布方式。
- **定時發布**：填香港日期及時間；預設為該課上課前一周09:00。保存後由伺服器時間判斷，不需要保持後臺開着。
- **立即發布**：已啟用並完成首次改密碼的學生可以取得。

老師可以閱讀所有未封存材料，無須等學生發布時間。管理員另可查看封存材料。封存可以還原，不刪檔；學生及老師不能下載封存材料。

替換檔案會使用新路徑並保留操作記錄。網站沒有舊檔版本瀏覽器；若要回復既有內容，從本機保留版本重新上傳。不要把帶答案的教師PPT換到原本公開的學生材料列。

有版本衝突時，先記下尚未儲存的內容，再重新載入核對另一人的變更。

## 課次與操作記錄

「課次與日期」可修改標題、簡介、上課時間及時長。更改上課日期不會自動改動已設定的材料發布時間；需要時到材料後臺逐項重設。

「操作記錄」顯示最近的新增、修改、封存、恢復及帳戶變更。網站帳戶不能修改記錄；資料庫備份與服務帳戶由專案負責人保管。
