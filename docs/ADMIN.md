# 課程後臺使用

## 帳戶

登入後打開「管理後臺 → 帳戶與權限」，搜尋姓名或電郵。核對報名資料後批准學生；老師及管理員角色只給有相應工作的教職員。權限修改有再次核對畫面，保存後會記錄操作。停用後新請求即失去存取權，已下載到他人電腦的文件不能遠端收回。

## 材料與發布

每項文件分開管理，可用課次、檔案狀態及文字搜尋篩選。新增材料先選檔案、課次和分類，再設定學生發布方式：

- **僅教職員**：學生永遠無法取得，除非管理員刻意改成其他發布方式。
- **定時發布**：填香港日期及時間；預設為該課上課前一周09:00。保存後由伺服器時間判斷，不需要保持後臺開着。
- **立即發布**：所有已批准學生可以取得。

老師可以閱讀所有未封存材料，無須等學生發布時間。管理員另可查看封存材料。封存是可還原的隱藏，不刪檔；學生及老師不能下載封存材料。

替換檔案會新建版本路徑，不覆寫原object。Portal保留操作記錄，沒有提供舊檔版本瀏覽器；若要回復既有內容，從本機保留版本重新上傳。不要把帶答案的教師PPT換到原本公開的學生材料列。

有版本衝突時，先記下尚未儲存的內容，再重新載入核對另一人的變更，不要反覆按存檔覆蓋。

## 課次

課次與日期可修改標題、簡介、上課時間及時長。更改上課日期不會默默改動已設定的材料發布時間；需要時到材料後臺逐項重設，避免已開放資料被意外改回。

## 操作記錄

後臺顯示最近的新增、修改、封存、恢復及帳戶變更。記錄不能由普通網站帳戶改写；資料庫備份與服務帳戶由專案負責人保管。不得把service-role金鑰交給老師或學生。
